# Support

## Questions and setup help

Use [GitHub Discussions](https://github.com/olivalcf/klaviyo-agent-skill/discussions) if enabled, or open a [support issue](https://github.com/olivalcf/klaviyo-agent-skill/issues/new/choose) with:

- agent and version;
- skill version or commit;
- Klaviyo connection type (listed connector, custom remote MCP, or local MCP);
- audit mode;
- read capabilities visible to the agent;
- sanitized error text.

Never post private API keys, OAuth tokens, profile data, recipient information, or raw account exports.

## What this project can support

- skill installation and discovery;
- audit methodology and scoring behavior;
- read-only MCP capability routing;
- validator and scorer errors;
- sanitized compatibility findings.

Klaviyo account access, connector OAuth, API availability, billing, and platform incidents should be directed to Klaviyo support. Agent-product installation or permission problems may also require the relevant vendor's support channel.
